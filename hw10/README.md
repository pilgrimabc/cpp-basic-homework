# Final project CPP-OTUS-BASIC

## Tensor Contraction (TenCon) lib

Это библиотека для работы с тензорными сетями и выполнении базовых операций с ними. Про то что такое тензорные сети
и зачем они нужны, можно почитать в двух статьях написанных в декабре прошлого года на хабре [Часть 1](https://habr.com/ru/companies/cloud_ru/articles/976884/)
и [Часть 2](https://habr.com/ru/companies/cloud_ru/articles/977806/). Для понимания достаточно первой части. Обе статьи 
написаны в научно-популярном формате, но этого правда достаточно. 

### Как поставить? 

Запуск достаточно простой: эта библиотека написана поверх существующей ```x-tensor```, т.к. я хотел использовать удобную 
NumPy-нотацию при разработке, и все же это учебный проект, поэтому могу себе позволить. Зависимости ставятся автоматически 
при первой сборке проекта прямо из ```cmake```-файла. То есть надо выполнить в терминале две привычные команды, находясь 
в директории проекта: 

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

### Что имеется? 

Переходим в папку ```examples/```. Там доступно пять выполняемых программ (см. в build). Кратко рассмотрим их по порядку: 

#### Example 1

Базовая работа с тензором: его инициализация (имя, индексы, данные). Операции ```reshape``` и ```transpose```, а также
доступ по элементу. Сразу скажу, что для тензора перегружен ```operator*```, чтобы удобно было сворачивать тензоры между 
друг другом (pairwise contraction).

#### Example 2

Демонстрация работы свертки на простом примере произведения матрицы и вектора.

#### Example 3

Запись тензоров в тензорную сеть (относитесь к ней как графу на стероидах: узлы это тензор, а ребра это индексы) и 
свертка этой самой сети (здесь просто pairwise contraction).

#### Example 4

Демонстрация работы оптимизатора свертки, тк задача выбора оптимального порядка свертки является **NP**-полной. Оптимизатор 
реализован самый простой -- я делаю дерево свертки и каждый раз выбираю для попарной свертки максимально затратное либо  по памяти, 
либо по операциям с плавающей точкой пару тензоров до тех пор, пока не останется последний тензор, являющийся результатом свертки тензорной сети. 

#### Example 5 

Демонстрация полной работы пайплайна.
