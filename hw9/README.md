В данном дз реализованы три различных подхода считать слова в файле (по образу и подобию предложенного решения):
1) Просто однопоточное решение (и так предложено в тексте дз) ```topk_words.cpp``` 
2) Реализация через ```mutex``` -- каждый поток читает свой файл и потом пишет результат в общий словарь -- ```mt1.cpp```
3) Реализация через асинхронные вызовы -- каждый поток запускается асинхронно и читает свой файл, пишет в свой словарь, а затем эти словари сшиваются в один общий -- ```mt2.cpp```

Для удобства экспериментов написал простой скриптик на питоне, в котором из командной строки можно указать количество файлов (если не указывать, то вызовется для одного файла). Пример: 
```bash
>> python3 bench.py 3

>> For 3 files:
>> ============================================================
>> Result for One-thread is Elapsed time is 253125 us
>> Result for Mutex is Elapsed time is 330488 us
>> Result for Aync local dics is Elapsed time is 142370 us
>> ============================================================
```

**Результаты:** решение (2) оказалось медленнее даже варианта (1), т.к. потокам пришлось пришлось простаивать в борьбе за общий словарь. Вариант (3) оказался быстрее всех, поскольку все потоки работали независимо друг от друга и простоя не возникало.
